🚗 Electric Vehicle Data Analysis Dashboard (Tableau)
📌 Project Overview

This project presents a comprehensive Electric Vehicle (EV) Data Analysis Dashboard built using Tableau. It provides insights into EV adoption trends, vehicle distribution, and performance metrics across different states, models, and manufacturers.

The dashboard helps stakeholders understand the growth of EVs, identify top-performing brands, and analyze eligibility metrics like CAFV.

🎯 Purpose of the Project
1.Analyze EV adoption trends over time
2.Identify top manufacturers and models
3.Understand geographical distribution of EVs
4.Evaluate CAFV (Clean Alternative Fuel Vehicle) eligibility
5.Provide data-driven insights for decision-making

📊 Key Insights & Features
🔹 KPI Metrics
1.Total Vehicles: 150,413
2.Average Electric Range: 67.83 miles
3.Total BEV Vehicles: 116,745 (77.6%)
4.Total PHEV Vehicles: 33,668 (22.4%)

🔹 Analysis Covered
📈 Total Vehicles by Model Year (Trend Analysis)
🗺️ State-wise EV Distribution (Map Visualization)
🏆 Top 5 Vehicle Manufacturers
⚡ CAFV Eligibility Breakdown

🚘 Vehicle Distribution by Model & Type
